# Machine Learning from Scratch

> **"What I cannot create, I do not understand."** — Richard Feynman

## Project Overview

This repository bridges the gap between **Abstract Mathematics** (Linear Algebra, Calculus) and **Applied Machine Learning**.

Unlike standard projects that rely heavily on `scikit-learn` or `TensorFlow` abstractions without explaining the underlying mechanics, this codebase is dedicated to implementing core algorithms **from first principles** using only Python and NumPy. The goal is to demystify the "black box" of AI by building the mathematical engine layer-by-layer. 

## The Knowledge Bank

This repository heavily emphasizes theoretical intuition before code. Our **Mathematics Foundation** serves as a structured textbook-style knowledge bank containing deep-dive lecture notes on all the prerequisite math needed to truly understand Neural Networks and ML frameworks. 

### Modules

| Module | Description | Key Concepts |
| --- | --- | --- |
| **00-Mathematics-Foundation** | The theoretical engine. | Vector Spaces, Matrix Algebra, Eigenvalues, SVD, PCA, Orthogonality. |
| **01-Core-Concepts** | Theoretical framework. | Bias-Variance Tradeoff, Error Analysis, Overfitting vs. Underfitting. |
| **02-Supervised-Learning** | The implementations. | Linear Regression, Logistic Regression, Decision Trees. |
| **03-Unsupervised-Learning** | Finding patterns. | K-Means, Clustering Algorithms. |
| **04-Data-Engineering-and-Eval** | Tying it together. | Feature Engineering, Pipelines, Evaluation Metrics. |

## Tech Stack

* **Language:** Python 3.x
* **Core Library:** NumPy (for vectorization and pure math operations)
* **Visualization:** Matplotlib / Seaborn
* **Philosophy:** No `sklearn.model.fit()`. Pure Logic.

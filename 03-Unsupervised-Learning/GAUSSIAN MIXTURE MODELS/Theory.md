# Gaussian Mixture Models (GMM) & EM Algorithm

## 1. Concept Overview
A **Gaussian Mixture Model** assumes that the data is generated from a mixture of several Gaussian distributions, each representing a cluster. Unlike K-Means (hard assignment), GMM performs **soft assignment** — each point has a probability of belonging to each cluster.

---

## 2. From K-Means to GMM

| Feature | K-Means | GMM |
| :--- | :--- | :--- |
| Assignment | **Hard** — each point belongs to exactly one cluster | **Soft** — each point has probabilities for all clusters |
| Cluster shape | Spherical (isotropic) | Elliptical (full covariance) |
| Underlying model | Distance to centroids | Gaussian distributions |
| Optimization | Lloyd's algorithm | **EM Algorithm** |

---

## 3. The GMM Model

A GMM with $K$ components is defined as:

$$
p(\mathbf{x}) = \sum_{k=1}^{K} \pi_k \cdot \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)
$$

| Term | Definition | Significance |
| :--- | :--- | :--- |
| $p(\mathbf{x})$ | **Probability density** of data point $\mathbf{x}$ under the GMM | The overall distribution is a weighted mixture of $K$ Gaussians; each point could have been generated by any component |
| $\pi_k$ | **Mixing coefficient** for component $k$ | Probability that a random point belongs to component $k$; must satisfy $\sum_{k=1}^{K} \pi_k = 1$ |
| $\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$ | **Gaussian density** for component $k$ | Each mixture component is a multivariate Gaussian with its own mean and covariance matrix |
| $\boldsymbol{\mu}_k$ | **Mean vector** of the $k$-th Gaussian | The "center" of the $k$-th cluster in feature space |
| $\boldsymbol{\Sigma}_k$ | **Covariance matrix** of the $k$-th Gaussian | Determines the shape, volume, and orientation of the $k$-th cluster |
| $K$ | Number of mixture components | Model hyperparameter; too few underfits, too many overfits (can be selected via BIC/AIC) |

---

## 4. The EM Algorithm (Expectation-Maximization)

Since we don't know which Gaussian generated which point (latent variables), we use the **EM algorithm** to iteratively estimate the parameters.

### E-Step (Expectation)
Compute the **responsibility** $r_{ik}$ — the probability that point $i$ was generated by component $k$:

$$
r_{ik} = \frac{\pi_k \cdot \mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)}{\sum_{j=1}^{K} \pi_j \cdot \mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)}
$$

| Term | Definition | Significance |
| :--- | :--- | :--- |
| $r_{ik}$ | Responsibility of component $k$ for point $i$ | Probability that point $i$ was generated by component $k$ — the "soft assignment" |
| $\pi_k$ | Mixing coefficient for component $k$ | Prior probability of component $k$ — how much of the total data it accounts for |
| $\mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$ | Gaussian density of point $i$ under component $k$ | How likely component $k$ is to have generated point $i$ |
| $\boldsymbol{\mu}_k$ | Mean vector of component $k$ | The center of the $k$-th Gaussian cluster |
| $\boldsymbol{\Sigma}_k$ | Covariance matrix of component $k$ | The shape/orientation of the $k$-th Gaussian cluster |
| $K$ | Total number of components | The number of Gaussian distributions in the mixture |
| $\sum_{j=1}^{K}$ | Sum over all components | Normalizes the responsibilities so they sum to 1 across components |

### M-Step (Maximization)
Update the parameters using the current responsibilities:

$$
\boldsymbol{\mu}_k = \frac{\sum_i r_{ik} \mathbf{x}_i}{\sum_i r_{ik}}, \quad
\boldsymbol{\Sigma}_k = \frac{\sum_i r_{ik} (\mathbf{x}_i - \boldsymbol{\mu}_k)(\mathbf{x}_i - \boldsymbol{\mu}_k)^T}{\sum_i r_{ik}}, \quad
\pi_k = \frac{\sum_i r_{ik}}{n}
$$

| Term | Definition | Significance |
| :--- | :--- | :--- |
| $r_{ik}$ | Responsibility — probability that point $i$ belongs to component $k$ | Computed in the E-step; weights each point's contribution to parameter updates |
| $\mathbf{x}_i$ | The $i$-th data point (feature vector) | One observation from the dataset |
| $\boldsymbol{\mu}_k$ | Mean vector of the $k$-th Gaussian component | The "center" of cluster $k$; updated as responsibility-weighted average |
| $\boldsymbol{\Sigma}_k$ | Covariance matrix of the $k$-th Gaussian | Determines the shape and orientation of the elliptical cluster |
| $\pi_k$ | Mixing coefficient for component $k$ | Probability that a random point came from component $k$; must sum to 1 across all $K$ components |
| $n$ | Total number of data points | Normalizes the sum to compute the weighted average |

### Convergence
Repeat E and M steps until the log-likelihood converges:

$$
\log p(\mathbf{X} \mid \boldsymbol{\pi}, \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \sum_{i=1}^{n} \log \left[ \sum_{k=1}^{K} \pi_k \cdot \mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \right]
$$

| Term | Definition | Significance |
| :--- | :--- | :--- |
| $\mathbf{X}$ | The entire dataset (matrix of all data points) | What we're evaluating the model on |
| $\boldsymbol{\pi}, \boldsymbol{\mu}, \boldsymbol{\Sigma}$ | All model parameters (mixing coefficients, means, covariances) | The parameters being optimized by EM |
| $\mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$ | Gaussian density of point $i$ under component $k$ | How likely component $k$ is to have generated point $i$ |
| $K$ | Number of Gaussian components (clusters) | The model complexity — must be chosen or selected via BIC/AIC |

---

## 5. Choosing the Number of Components

### BIC (Bayesian Information Criterion)
$$
\text{BIC} = -2 \log p(\mathbf{X}) + p \log n
$$

| Term | Definition | Significance |
| :--- | :--- | :--- |
| $p(\mathbf{X})$ | Likelihood of the data given the model | Higher is better — the model explains the data well |
| $p$ | Number of estimated parameters in the model | More parameters = more complex model |
| $n$ | Number of data points | Larger datasets get a bigger penalty for complexity |

Lower BIC is better. It penalizes model complexity (more components).

### AIC (Akaike Information Criterion)
$$
\text{AIC} = -2 \log p(\mathbf{X}) + 2p
$$

| Term | Definition | Significance |
| :--- | :--- | :--- |
| $p(\mathbf{X})$ | Likelihood of the data given the model | Same as BIC |
| $p$ | Number of estimated parameters | Same as BIC |
| $2p$ | Penalty term | Weaker penalty than BIC — tends to select more complex models |

Similar to BIC but with a weaker penalty.

## 6. Code Example

```python
from sklearn.mixture import GaussianMixture
from sklearn.datasets import make_blobs
from sklearn.metrics import silhouette_score
import numpy as np

X, y_true = make_blobs(n_samples=300, centers=3, random_state=42)

# Fit GMM with different k
bic_scores = []
for k in range(1, 7):
 gmm = GaussianMixture(n_components=k, random_state=42)
 gmm.fit(X)
 bic_scores.append(gmm.bic(X))

best_k = np.argmin(bic_scores) + 1
print(f"Best k by BIC: {best_k}")

# Final model
gmm = GaussianMixture(n_components=3, random_state=42)
labels = gmm.fit_predict(X)
probs = gmm.predict_proba(X) # Soft assignments

print(f"Cluster means:\n{gmm.means_}")
print(f"Mixing coefficients: {gmm.weights_}")
print(f"Silhouette Score: {silhouette_score(X, labels):.3f}")
```

## 7. GMM vs. K-Means

| Scenario | Better Choice |
| :--- | :--- |
| Clusters are spherical | K-Means (simpler, faster) |
| Clusters are elliptical or overlapping | GMM |
| You need soft probabilities | GMM |
| Large dataset (>10K points) | K-Means |
| You want model selection metrics | GMM (BIC/AIC) |

---

## 8. Advantages & Disadvantages

### Pros
* **Soft clustering** — probabilities are more informative than hard labels.
* Flexible cluster shapes (full covariance matrices).
* Principled model selection (BIC/AIC).
* Probabilistic framework — can handle overlapping clusters.

### Cons
* Sensitive to initialization (like K-Means).
* Can converge to local optima.
* Assumes Gaussian distributions (may not fit real data).
* More parameters to estimate than K-Means.
